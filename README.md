
# Bot Telegram Waitlist V3 Complet

Bot Telegram Python pour Railway + PostgreSQL.

## Inclus

- Panel admin avec boutons inline
- Captcha fruit sans nom sur les boutons
- Message d'accueil avec image
- Suppression des anciens messages du bot au /start
- Formulaire utilisateur complet
- Si refus : une seule seconde demande possible
- Deuxième refus : blocage définitif
- Motif de refus admin
- Listes d'attente par catégorie
- Détection des groupes où le bot est ajouté
- Création de publicités image + texte
- Publication des publicités dans les groupes connectés
- Broadcast par liste d'attente

## Variables Railway

BOT_TOKEN=
DATABASE_URL=
ADMIN_IDS=123456789,987654321
WELCOME_IMAGE_URL=https://...

## Commandes

Utilisateur : /start
Admin : /admin

Tout le reste se fait avec les boutons du panel admin.
