
# Telegram Waitlist Bot

Bot Telegram avec :
- formulaire d'inscription
- captcha fruit
- validation admin
- listes d’attente
- PostgreSQL
- prêt pour Railway

## Installation

```bash
pip install -r requirements.txt
```

## Variables Railway

```env
BOT_TOKEN=YOUR_TOKEN
DATABASE_URL=postgresql://...
ADMIN_IDS=123456789
```

## Lancer

```bash
python main.py
```
